33 minutes→resets in 33m

  • Bars thin & flat — no gradients, no glows, subtle rounded caps.
  • Healthy secondary = grey fill, so green never multiplies.
  • Amber appears at most twice: header verdict + the affected row. The percent stays white; only the reset text and bar go amber.
  • No chips — color and header copy carry the alert.
  • Layout constant across states — only color changes, like the battery icon.

The disclosure rules

  • Collapsed = main limit. Each provider shows only its shortest-cadence window; the chevron › reveals the rest. Today that's Claude's 5-hour and Codex's Weekly. On Codex plans that include a 5-hour limit, that window takes the collapsed slot and Weekly moves behind the chevron. No special cases.
  • The chevron toggles the provider, and the choice is remembered per provider — Claude open, Codex closed, independently.
  • Amber auto-surfaces, low does not — a use-soon limit breaks through a collapsed card; a merely-low one waits for expand.
  • Live, too — if a limit crosses the amber threshold while the panel is already open, its row appears right then; when it calms, it tucks back away. Only the amber row surfaces — the rest of the card stays collapsed, and your saved expand/collapse choice is never overwritten.
  • Hidden windows are still measured: they can go amber, fire notifications, and surface — disclosure changes what's drawn, never what's measured.
  • Droplet and verdict follow the main window of each provider, exactly as today. Amber from any window turns them amber. One exception, lockout: when a limit that blocks the whole provider is exhausted (the all-models Weekly at 0%), that provider reads as empty. A model-specific weekly such as Fable running out only mutes its own row.
  • This replaces the Show Weekly / Show Fable settings toggles — disclosure is the curation, in the panel where you actually look.

The title rule

Title scope — narrowest that covers all amber
  • 1 window → name it · "Use your Fable juice", and the subtitle drops the name.
  • >1, one provider → name the provider · "Use your Claude juice"
  • e.g. Codex 5-hour & Weekly both amber → "Use your Codex juice"
  • across providers → "Use your juice"
Ranking
  • Soonest reset first.
  • Tie (same reset boundary) → higher remaining % wins — more juice at stake.
Subtitle
  • Soonest first; coalesce same-reset windows in row order. Every group carries its verb ("Weekly & Fable reset in 23h", "5-hour resets in 33m").
  • Count form drops the em-dash ("<N> limits reset soon · <soonest window> resets in <t>").
  • Enumerate only if it fits the header line; otherwise fall to the count form early — never ellipsize (the two-group cross-provider case is the borderline one).
Count ladder
  • 1 amber → title names it, subtitle drops the name.
  • ≤ 2 groups after coalescing → enumerate ("5-hour resets in 33m · Weekly & Fable reset in 23h").
  • > 2 groups → true count + soonest ("3 limits reset soon · …", "4 limits…", "5 limits reset soon · Claude 5-hour resets in 33m").
Rows always show their own amber independently — rows are facts, the header is the one voice. Windows going amber at the same moment coalesce into a single notification.

Summary

  • Apple anatomy and the reset standard are locked: floored to one unit, always the words "resets in", one formatter shared verbatim by every row, the header, and every notification.
  • Ship per-provider disclosure — collapsed to the main limit, a chevron to expand, the choice remembered per provider — with the safety rail that amber always surfaces and low never does.
  • The header is one voice: the scope cascade window → provider → generic, soonest-reset ranking, same-boundary coalescing. Rows stay independent facts; title and subtitle are a pure function of the amber set, reused by the panel and the coalesced notification.
  • Ship Window B in Settings — visibility lives in the panel now, so Settings keeps only the use-soon thresholds, one pair per cadence (5-hour and weekly), both feeding the same amber grammar.
  • The row set follows what each provider reports, classified by window duration: Claude's 5-hour, Weekly and Fable; Codex's Weekly, plus a 5-hour on the plans that include one.
